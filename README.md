## Overview

**CineZone** is a modern movie theater management system designed to optimize ticket sales, online booking, showtime scheduling, cinema room and employee management, and promotions. CineZone aims to enhance operational efficiency, deliver a seamless customer experience, increase revenue, and boost competitiveness in the cinema market.

## Features

- User registration, login, and account management
- Online movie ticket booking (choose movie, showtime, seats)
- Ticket selling and booking management for staff
- Movie, cinema room, and showtime management
- Member, employee, and promotion management
- Ticket history, rewards/points tracking, reporting, and statistics

### Main User Roles

- **Admin:** Full system management rights (add/edit/delete modules, manage employees, members, cinema rooms, statistics, etc.)
- **Employee:** Manage ticket sales and booking, search for customers
- **Customer:** View movie list, promotions, ticket prices, showtimes, and register an account
- **Member:** All customer features plus ticket booking, account management, and rewards

## Installation

> **Note:** CineZone is currently a sample/educational project. Please add a detailed installation guide suitable for your environment as development progresses.

1. **Clone the project from GitLab:**
    ```sh
    git clone https://git.fa.edu.vn/hcm25_cpl_react_05/fe_team_1.git
    ```

2. **Install dependencies:**
    ```sh
    cd cinezone
    npm install
    ```

3. **Start the application:**
    ```sh
    npm start
    ```

## Usage

- After running the app, visit [http://localhost:8080](http://localhost:8080) (or the appropriate URL).
- Register a new account or log in to access system features.
- Depending on your user role, you can book tickets, manage cinema rooms or employees, and view system statistics.
